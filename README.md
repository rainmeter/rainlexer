## RainLexer Releases

RainLexer adds syntax highlighting support for Rainmeter .ini configuration files to Notepad++.

Note that this project only hosts the [RainLexer releases](https://github.com/rainmeter/rainlexer/releases). The source code has been moved into the main [Rainmeter repo](https://github.com/rainmeter/rainmeter/tree/master/RainLexer).
